# Character Replacement (Video Edit) Rewrite Output Format Guide

This is a local specialization of MiniMax's official `ref-en.txt`, not a separate official MiniMax skill. Read the official Ref2VA guide for section order, labels, retention markers, shot notation and audio roles. This document adds the source-performance/reference-appearance contract for character replacement.

Sources:
- Official format: https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt
- Adapter model card: https://huggingface.co/akatz-ai/MiniMax-H3-Character-Swap-LoRA
- Adapter examples: https://huggingface.co/akatz-ai/MiniMax-H3-Character-Swap-LoRA/tree/main/examples

The Akatz V1.5 adapter takes a source performance as `<Video 1>` and a reference identity as `<Picture N>`. Its example asks to keep the reference face, hair and clothing while following source pose, gaze, expression and movement. No extra trigger word is required. Its examples use direct requests; more preservation or expression wording is not a guarantee of stronger adherence. Sampling recipes are workflow settings, not prompt instructions.

## 0. Iron rules for this task

1. **Appearance authority.** Reference pictures supply the replacement face, hair, ears, clothing, proportions, distinguishing features and art style. The source video supplies performance, expression, position, visibility, interactions, camera, lighting, environment and timing. Explicit user requests such as a face-only swap or retaining the source outfit override the default only for that attribute.
2. **Subject bindings.** For a single replacement, `<Subject 1>` is the reference identity and `<Subject 2>` is the source person whose performance is transferred. Use stable labels for other people. Numbering stays unchanged through crossings, exits, re-entry and segment boundaries.
3. **Source evidence and edited target are different.** Keep original appearance descriptions in the audit/analysis used to identify the source target. Final `detailed_description` describes the EDITED target with the reference identity already in place. Do not rename a source observation and thereby assign original clothing to the replacement. For example, source gold fabric flaring during a turn does not instruct the replacement to wear gold; describe the reference robe responding to that turn.
4. **Identify the target uniquely.** Resolve rules, P codes or appearance-based instructions using the observed source cast. For multiple people, retain enough source identification cues to track the correct role; screen position alone is insufficient. For a sole source person, a long description of original clothes and hair is unnecessary in the final prompt.
5. **Appearance comes only from supplied evidence.** Preserve user names and trigger words verbatim. A multi-view character sheet represents one identity; views are not extra people. Do not show the reference sheet or its background.
6. **Only actual source population appears.** Preserve unassigned people and their appearance. Keep source entrances, exits, occlusions and interactions. Do not spawn a reference person in a window where its assigned source role is absent.
7. **Anti-copy clause: replacement starts immediately.** From the first visible frame of the assigned source role, the reference identity occupies it. The opening frame is already replaced. Do not describe a reveal, morph, delayed swap, or transition from the original identity. After re-entry the reference identity remains the same.
8. **Stable identity across segments.** Reuse the reference identity description verbatim. Prevent reverting to the original identity or appearance drift. Request source pose, gaze, expression and movement concisely; do not repeat a long list of per-frame expression constraints or freeze the reference face into its neutral card expression.
9. **Local timeline.** Each segment describes only its actual source window. MC overlap is continuation, not a new opening. Do not repeat a full-film fade or ending in each window. Only source-supported cuts, light changes and events appear at their proper local times.
10. **Collateral and physical response.** Preserve held objects and hand interactions. Apply source illumination and motion naturally to the reference appearance; source clothing does not become a target wardrobe lock. Do not invent new actions to resolve an outfit difference.
11. **Official format.** Write all six sections in English; dialogue, lyrics and visible text retain the source language. Use official retention markers: `fully_preserved`, `partially_preserved`, `attribute_transfer`, `weak_reference`. Do not invent a `replaced` retention marker.
12. **Audio.** If the source soundtrack is supplied and reused, define its synchronized `<Audio N>`, include `audio reuse` in the summary, and record `fully_copy`. Reuse existing score rather than claiming `N/A` when the source contains music. Do not infer new speech or music from sampled stills.
13. **Output only the final prompt.** No commentary or code fences. When generating a structured analysis plan instead, keep source observations and target descriptions in separate fields; the renderer compiles target fields into the six-section prompt.

## 1. Six-section example

Adapt this to the actual references, user exceptions, source population and local timeline. Avoid repeating general rules as long instruction lists.

```text
subject_definitions:
<Subject 1> is the character from <Picture 1>, with silver-blue hair, fox ears and a white robe with gold trim.
<Subject 2> is the sole source person in <Video 1> whose performance is transferred to <Subject 1>.
<Video 1> is the current source video window being edited.
<Audio 1> is its synchronized original soundtrack, reused in the delivered edit.

summary:
[video editing + reference generation + audio reuse] The target video is an edited version of <Video 1>. Replace only <Subject 2> with <Subject 1> while preserving the source performance, scene and timing.

retention_analysis:
<Subject 1>: attribute_transfer - reference face, hair, outfit and proportions define the replacement.
<Subject 2>: partially_preserved - source performance, position and visibility are transferred; appearance changes to the reference identity.
<Video 1>: partially_preserved - retain source camera, lighting, background, population and timing while applying requested edits.
<Audio 1>: fully_copy - reuse the synchronized source soundtrack.

detailed_description:
From its first visible frame, <Subject 1> already occupies the source role with the complete reference appearance. Keep this identity through turns and occlusion; do not morph from or revert to <Subject 2>. Do not show the reference sheet or its background.
[Shot 1] <Subject 1>, with silver-blue hair, fox ears and the white-and-gold reference robe, dances alone on the dark stage under the source spotlight. She opens her arms, turns into profile and steps forward; the white robe and silver-blue hair respond naturally to the turn. Follow the source pose, gaze, expression and movement. Preserve source framing, background and actual light changes. Remove the requested watermark.

overall_soundscape:
Reuse the synchronized source soundtrack from <Audio 1>; add no new speech or sound.

non_diegetic_music:
Reuse any source score through <Audio 1>; add no new music.
```
