MOSS-Image layout draft guide (derived from the official prompt-enhancer skill's
references/layout.md).

Schema: one readable JSON object, nothing else.

- width, height: positive integers, multiples of 16, equal to the canvas the node
  gives you (and to the sampler resolution). They are draft metadata and are
  omitted from the compiled prompt. Do not rescale boxes by changing them.
- bbox_coord_space: exactly "abs".
- bbox_format: exactly "xyxy".
- summary: an object with a nonempty "caption" describing the whole image
  (medium, subject, setting, lighting, palette, typography treatment). Optional
  "meta" (array of medium/genre tags) and "canvas" ("single", "multi_panel" or
  "collage") are accepted.
- items: a nonempty flat array. Each item has:
  - label: "object", "character" or "text".
  - caption: nonempty description of its visible appearance; for text, also
    typography and surface treatment.
  - bbox: four numbers [x_min, y_min, x_max, y_max] in actual pixels from the
    canvas top-left. Keep 0 <= x_min < x_max <= width and 0 <= y_min < y_max <= height.
  - text: required for a "text" item; the exact visible characters, with literal
    intended line breaks as JSON \n. Use separate text items when placement must
    be independent.
  - palette (optional): array of colour strings. tags (optional): array of tags.
- Do not add children, parent, id, scene-schema elements or presentation notes.
  Do not emit the compiled form yourself: never use "abs_centralized", "yxyx",
  negative coordinates, or the model's compact one-line JSON.

A box is a placement annotation, not an instruction to draw a border, panel or
sticker. Describe appearance in captions and global treatment in summary.caption,
and keep the boxes consistent with the prose. Natural occlusion and overlap are
allowed; several items may share or overlap a box.

Example draft for a 1536x1024 campaign image with a cup and Chinese copy:

{
  "width": 1536,
  "height": 1024,
  "bbox_coord_space": "abs",
  "bbox_format": "xyxy",
  "summary": {
    "meta": ["product campaign", "studio photography"],
    "canvas": "single",
    "caption": "A warm studio campaign for a handmade ceramic cup, with an ivory backdrop, soft side lighting and restrained dark-green typography. Keep the ceramic texture tactile and the composition calm."
  },
  "items": [
    {
      "label": "object",
      "caption": "An ivory ceramic cup with a rounded handle, fine speckled glaze and a soft contact shadow, photographed at a three-quarter angle.",
      "bbox": [176, 224, 800, 864]
    },
    {
      "label": "text",
      "caption": "Large dark-green Chinese title in crisp, moderately heavy lettering, with generous spacing and no backing panel.",
      "text": "把日常，过成诗。",
      "bbox": [928, 272, 1408, 448]
    },
    {
      "label": "text",
      "caption": "Smaller dark-green Chinese supporting copy, comfortably legible on two lines.",
      "text": "一杯温暖\n一刻从容",
      "bbox": [928, 512, 1376, 656]
    }
  ]
}

Composition checks before answering
- Read every visible string against the requested wording. Keep line breaks,
  text length and glyph scale able to fit the box at the declared resolution: a
  short Chinese title needs a different footprint from a paragraph of Latin text.
- Enlarge or recompose an unreadable layout instead of silently deleting copy or
  stretching glyphs.
- For a knowledge graphic, develop actual explanations and explanatory imagery;
  do not substitute empty modules. For a poster, keep its visual identity and
  information hierarchy rather than forcing infographic organisation.
- Keep one coordinate convention throughout: pixels, top-left origin, xyxy.
